# PlayGround

## 遊戯王 DUEL ARENA

ブラウザだけで遊べる、遊戯王風の1対1カードデュエルです。カードの絵はすべてインラインSVGで描画しています。

- 8000 LP・30枚デッキ・モンスター/魔法・罠ゾーン各5枠
- 召喚、生贄召喚、裏側守備、魔法発動、罠セット、ダイレクトアタック
- 手札をタップ/クリックし、画面下のアクションバーから行動を選択
- 相手AIと対戦。デスクトップ・スマートフォンの両方に対応

> ファンメイドの非公式作品です。原作・権利者とは関係ありません。
